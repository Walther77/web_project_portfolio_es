# Portafolio

¡Bienvenido/a a mi portafolio web! Este proyecto fue desarrollado como parte del Sprint 4 de TripleTen, con el objetivo de crear una presentación digital donde pudiera mostrar mi perfil, mis habilidades, las herramientas que estoy aprendiendo y algunos de mis proyectos.

## Descripción del proyecto

Este portafolio presenta mi perfil como desarrollador web junior y reúne diferentes elementos relacionados con mi formación en desarrollo Front-End.

El diseño fue desarrollado tomando como referencia un brief realizado en Figma y adaptado para diferentes tamaños de pantalla, buscando mantener una estructura clara, organizada y responsive.

## ¿Qué encontrarás aquí?

- **Perfil profesional:** presentación, descripción y enlaces de contacto.
- **Habilidades y herramientas:** tecnologías y herramientas utilizadas durante mi formación.
- **Proyectos destacados:** presentación visual de proyectos realizados.
- **Información de contacto:** correo electrónico y enlaces a redes sociales.
- **Diseño responsive:** adaptación para escritorio, tablet y dispositivos móviles.

## Tecnologías utilizadas

- HTML5
- CSS3
- Git
- GitHub
- Figma

## Características técnicas

- **HTML5 semántico:** estructura organizada para las diferentes secciones del portafolio.
- **CSS3:** estilos personalizados, degradados y efectos visuales.
- **Diseño responsive:** adaptación para diferentes tamaños de pantalla mediante media queries.
- **Flexbox y CSS Grid:** utilizados para organizar y distribuir los elementos de la página.
- **Metodología BEM:** organización de las clases CSS para mantener un código claro y estructurado.
- **Diseño basado en Figma:** uso de especificaciones de diseño como referencia para tamaños, espacios, tipografías y distribución.

## Resoluciones trabajadas

El diseño fue adaptado para las siguientes resoluciones:

- Desktop: 1440px
- Tablet: 768px
- Mobile: 320px

También se realizaron pruebas en tamaños intermedios para comprobar el comportamiento responsive.

## ¿Cómo se hizo?

- Se analizó el diseño proporcionado en Figma.
- Se construyó la estructura HTML del portafolio.
- Se aplicaron los estilos utilizando CSS.
- Se implementaron diferentes breakpoints para adaptar el contenido a cada resolución.
- Se realizaron pruebas visuales y ajustes para mantener la similitud con el diseño original.
- Se organizaron los archivos del proyecto siguiendo buenas prácticas de desarrollo.
